Конвертер ТТ → формы СУО

Формы ввода 2R (страновой риск), R3 (валютный риск), 4R (процентные разрывы) из трансформационной таблицы
Загрузите файл ТТ (xlsm/xlsx) — консолидированную трансформационную таблицу за отчётный период.
Проверьте период, компанию, курс USD/KZT и итоги контроля (вкладка «Контроль»).
При необходимости поправьте ячейки прямо в предпросмотре форм R3 / 2R / 4R.
Сохраните период в историю и скачайте заполненную форму СУО в Excel.

Параметры отчёта

Курс нужен для проверки порога 1 млн долл. США по форме R3 и для аналитики. Единицы измерения: тыс. тенге (как в ТТ и формах).

Сводка по загруженному периоду

Форма R3 — отчёт о величине валютного риска

тыс. тенге по курсу бухгалтерского учёта. Ячейки со значениями можно редактировать; правки подсвечены и попадают в выгрузку.

Форма 2R — страновой риск

Активы и условные обязательства по стране налоговой регистрации контрагента, тыс. тенге. Страновой лимит и рейтинг задаются в настройках.
Разнесение денежных средств и вкладов по банкам
Выручка по странам (база для распределения торговой ДЗ)

Форма 4R — процентные разрывы в разрезе валют

В форму попадают только инструменты, чувствительные к изменению ставок (плавающая ставка). Коэффициенты чувствительности по категориям — в настройках.
Валовые суммы по срокам до применения коэффициентов чувствительности

Сверка формы R3 с балансом ТТ

Журнал преобразования

«warn» — расхождения, требующие внимания; «note» — допущения маппинга (суммы без валютного/странового разреза); «info» — справочно.

    Ключевые показатели

    Чистая валютная позиция по валютам, динамика

    тыс. тенге; по сохранённым периодам и текущему

    Активы и обязательства по валютам, текущий период

    тыс. тенге, без тенге

    Страновой риск: крупнейшие позиции

    итого по стране, тыс. тенге

    Процентный разрыв по временным интервалам

    чувствительные активы минус обязательства, тыс. тенге

    Общие

    Подписи

    Коэффициенты чувствительности к процентной ставке (4R)

    Доля позиции (0–1), относимая к чувствительным инструментам. «auto» для займов полученных — доля займов с плавающей ставкой по ТТ.

    Справочник банков → страна (2R)

    Для банков без страны в названии. Названия — как в ТТ. Пустое значение — автоопределение.

    Страновые лимиты и рейтинги (2R, графы 10 и «Рейтинг страны»)

    Лимит в тыс. тенге по СТП КМТФ.033/.034 (потолок — 50% собственного капитала). Заполняется вручную по реестру лимитов.
