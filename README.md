# Сыфаты в таджвиде — интерактивный курс

Образовательное веб-приложение, которое превращает «тёмный лес» сыфатов (свойств арабских букв
в таджвиде) в понятную, последовательную и визуальную систему: 12 уроков, интерактивные схемы
артикуляции, карта сыфатов, тренажёры, тесты и проверенные видеоматериалы.

**Педагогический принцип:** почувствовать → увидеть → понять → услышать → повторить → проверить себя.
Каждый термин сначала переживается на собственном произношении и только потом получает название.

## Запуск

```bash
npm install
npm run dev        # режим разработки (http://localhost:5173)
npm run build      # production-сборка (tsc + vite) в dist/
npm run preview    # предпросмотр production-сборки
```

Проверки качества:

```bash
npm run lint          # ESLint
npm run typecheck     # TypeScript
npm run check-data    # целостность учебных данных (буквы, сыфаты, примеры, уроки)
npm run check-videos  # структура базы видеоссылок
npm run check-videos -- --network  # + проверка существования роликов через YouTube oEmbed
```

Браузерные e2e-скрипты (нужен `vite preview` на :4173 и Chromium;
путь к бинарю — переменная `CHROMIUM_PATH`):

```bash
node scripts/e2e/smoke.mjs      # все маршруты, desktop + mobile, ошибки консоли
node scripts/e2e/journey.mjs    # полный пользовательский путь: онбординг → уроки → практика → тест
node scripts/e2e/screenshots.mjs
```

## Структура

```
src/
  data/            # единый source of truth учебного контента
    sifat.ts       #   17 сыфатов (классификация Ибн аль-Джазари)
    letters.ts     #   29 букв: махраджи; сыфаты букв ВЫВОДЯТСЯ из sifat.letters
    lessons/       #   контент 12 уроков (структурированные блоки, без JSX)
    videos.ts      #   база видео с полями verified/needs-verification
    quran-examples.ts  # проверенные примеры (сура:аят) с разбором букв
  types/           # все типы контента и прогресса
  lib/             # storage, app-state (контекст), генераторы заданий, поиск, арабские утилиты
  components/
    layout/        # каркас, навигация, поиск, тема, онбординг, акварельный слой
    diagrams/      # SVG-схемы: ротовая полость, поток воздуха, шкала течения, дерево сыфатов…
    lesson/        # рендер блоков урока, карточки, мини-тест
    quiz/          # движок тестов (выбор, мультивыбор, сопоставление, классификация)
    practice/      # флешкарты, «Разложи по полочкам»
    video/         # карточка видео с фасадом (iframe грузится по клику)
  pages/           # маршруты приложения
scripts/           # проверки данных и e2e
```

Ключевое архитектурное правило: списки букв каждого сыфата заданы **один раз** в
`src/data/sifat.ts`; сыфаты буквы (`letter.sifatIds`) вычисляются из них. Уроки, карточки,
таблицы, тренажёры и тесты используют одни и те же данные, поэтому не могут разойтись.
Учебный текст, видео и примеры редактируются в `src/data/**` без изменения компонентов.

## Методическая основа

Классификация — «Мукаддима» Ибн аль-Джазари: 17 сыфатов (5 групп противоположных + 7 без
противоположности), 29 букв (хамза и алиф считаются отдельно). Подробности и ограничения —
на странице «О курсе».

Материал предназначен для облегчения изучения таджвида и не заменяет обучение
у квалифицированного преподавателя.
